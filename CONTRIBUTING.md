# Contributing to Manoj’s portfolio

Keep changes focused and preserve the site's visual language and responsive behavior.

## Report a problem

Include the affected page, expected behavior, actual behavior, browser, and screen size. Screenshots or a short recording help explain visual issues.

## Make a change

1. Create a branch from `main`.
2. Install dependencies with `npm ci` and run `npm run dev`.
3. Make the change without adding secrets, generated build output, or unrelated assets.
4. Run `npm run typecheck` and `npm run build`.
5. Describe the resulting behavior and relevant verification. Include screenshots for visual changes.

Keep the copyright and permission notices in `LICENSE` when redistributing licensed code.
